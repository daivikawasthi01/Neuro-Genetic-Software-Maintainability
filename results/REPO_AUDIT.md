# Repository Audit

Generated for Tier 1 reproducibility work. Source checkout at audit time:
`b29fec0700cd465d9ea5cdbbf65d39b9cf2e642f`.

## Pipeline map

1. `main.py` orchestrates collection, preprocessing, Optuna ANN tuning, GA,
   baselines, ablation, statistics, multi-repository execution, sensitivity,
   and report generation.
2. `src/data_collector.py` extracts AST/radon structural and textual metrics,
   Git evolutionary metrics, and the keyword-based future bug-fix target.
3. `src/preprocess.py` clips numeric outliers and removes correlated columns
   where `|r| > 0.95`; scaling is deferred until each train/validation split.
4. `src/ann_model.py` defines and trains the PyTorch ANN. It loads frozen
   hyperparameters from `data/results/best_hyperparams.json` when present.
5. `src/genetic_algorithm.py` owns chromosome generation, tournament
   selection, crossover, mutation, checkpointing, and fitness memoization.
6. `src/baseline.py`, `src/ablation.py`, and `src/stats.py` generate the main
   comparison, category ablation, and paired significance artifacts.

## Feature audit

The collector currently computes 19 numeric candidate metrics plus
`target_bug_proneness` and `file_name`. `weighted_methods_per_class` and
`docstring_presence` are real computed columns, not dead paper-only names.
The checked-in Flask raw dataset has shape `(83, 21)` and contains both.
The cleaned Flask dataset has shape `(80, 19)` and contains 17 numeric
features after correlation filtering. The canonical lists are in
`src/constants.py`; their names therefore describe the current implementation,
not the paper's intended 19-feature wording.

## Trial counts, seeds, and statistics

Before this work, `main.py` defaulted to 20 trials while module defaults and
seed formulas differed (`trial * 7 + 13`, `trial * 11 + 7`, and `trial * 7`).
The shared default is now `n_trials=20`, `base_seed=42`, with trial seed
`base_seed + trial_index`. Python, NumPy, PyTorch, GA initialization, and
cross-validation splits are seeded through `src/reproducibility.py`.

The Wilcoxon test is in `src/stats.py`. It is paired, two-sided, and now
records the exact statistic, p-value, zero handling, raw paired values, and
paired Cohen's d.

GA fitness memoization is held in memory and serialized in the GA checkpoint
with chromosome and split seed. The checkpoint path is now experiment-specific
and includes the dataset filename and base seed. Existing generated JSON files
were created without complete provenance and are not treated as authoritative
for the Tier 1 rerun.
